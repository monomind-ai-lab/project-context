# Example: returning to a research report after three weeks

An agent begins with [`NOW.md`](NOW.md), learns the active constraint from
[`DECISIONS.md`](DECISIONS.md), and reuses the verified operational lesson in
[`LEARNINGS.md`](LEARNINGS.md). It does not need the original chat session.

This compact, non-code example demonstrates the core profile. The same pipeline
works for software, documents, research, writing, and mixed repositories. A full
profile adds task, design, and incident evidence folders.
