# Project Context

> Category: Brands

> Surface: web

*Clarity comes with context.*

Project Context is a small, agent-operated context pipeline — NOW.md, DECISIONS.md, LEARNINGS.md, and linked evidence — that keeps a project's durable state, decisions, and verified learninigs portable across collaborators, agents, and tools. Git-tracked, plain Markdown, owned by the project.

## Color Palette

| Role | Name | Hex | Usage |
| --- | --- | --- | --- |
| background | Background | `#ffffff` | page canvas |
| foreground | Foreground | `#111111` | body text and headings |
| accent | Accent | `#1c4d60` | primary actions and emphasis — "Ink Teal", sampled from the deep petrol-teal field in project-context-cover.jpg |
| surface | Surface | `#f3f8fa` | cards and panels — accent hue at very low chroma/high lightness |
| muted | Muted | `#5d6c72` | secondary text and metadata — accent hue at reduced lightness/chroma |
| border | Border | `#cedadf` | rules and dividers — accent hue at light tint |

## Typography
- **Display:** General Sans — weights 600, 700 — fallbacks: system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif
- **Body:** Inter — weights 400, 500, 600 — fallbacks: system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif

## Voice & Tone

- **Adjectives:** precise, calm, portable, evidence-based, plainspoken
- **Tone:** Precise, calm, and infrastructure-grade — a developer-tool voice that treats Markdown and Git as first-class continuity, not paperwork. Direct and unembellished, matching the cover tagline: "Clarity comes with context."

### Messaging pillars
- Shared project context that outlives any one person, agent, or chat.
- Answers four questions: what's true now, which decisions constrain the work, what's already been learned, and where the evidence is.
- Agent-operated and human-readable — people provide intent and approve changes; agents read, maintain, and verify the Markdown.
- Context stays portable and owned by the project, not locked in chat history, proprietary memory, or generated documentation.

### Vocabulary
- **Use:** context, evidence, durable state, decisions, learnings, portable, agent-operated
- **Avoid:** chat history, proprietary memory, magic, auto-generated docs

## Imagery

- **Style:** Moody, duotone-leaning photography: a soft-focus warm terracotta field blended with a deep ink-teal field, no hard edge between them.
- **Subjects:** Abstract, non-representational blur — no literal product shots or people
- **Treatment:** Full-bleed photographic backdrop with a thin 1px white geometric line accent (open square + underline rule) and tightly tracked, all-caps white type set directly over the photo.
- **Avoid:** Sharp literal photography, A second accent color introduced into the photo treatment, Gradients used as a substitute for the photographic duotone

## Layout

- **Radius:** 8px
- **Border weight:** 1px
- **Spacing:** 8px baseline grid

### Posture rules
- Component kit should cover: Button, Card, Form, Navigation.
- A thin 1px line is a legitimate stand-alone accent (square outline, rule, index marker) — not only a border on containers.
