02 using a deck

One HTML file, nothing to install

Each deck is a single page. Nothing is downloaded, nothing is tracked, and it works offline once the page has loaded. Present it, or read it at your desk — it is built to survive both.

Move through it

Arrow keys, Space, PageUp / PageDown, Home and End. Scroll or swipe works too. On a phone the deck becomes a vertical read rather than a slideshow.

Jump anywhere

The Contents item in the menu lists every slide by name, built from the slides themselves so it cannot drift out of step. A deck stays useful as a reference after the talk is over, and your position is remembered if you close the tab and come back.

Take it with you

The menu will save the deck a copy of itself — one file, no assets folder, opening exactly as it does here. There is a light theme in there too. Both decks are English only; command text and file names would not survive translation anyway.
