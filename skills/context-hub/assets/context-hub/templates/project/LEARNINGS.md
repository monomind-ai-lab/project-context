# Learning Registry

Promote only evidence-backed lessons that will recur beyond one task. Use stable
IDs such as `L-001`; mark replaced entries `superseded` rather than rewriting
their historical meaning.

## L-000: Example learning

- Status: `proposed`
- Date: YYYY-MM-DD
- Scope: Name the systems, projects, or workflows where this applies.
- Asserted by: actor-example
- Recorded by: actor-example
- Approved by: none
- Learning: State the reusable lesson precisely.
- Action: Say what future collaborators should do differently.
- Evidence: `episode:episode-example` or
  `repo:product-main:path/to/file@<commit>`
- Supersedes: none
- Superseded by: none
