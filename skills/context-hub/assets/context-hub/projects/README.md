# Projects

Create `projects/<project-id>/` from [`../templates/project/`](../templates/project/).
Add `entities/`, `relationships/`, and `insights/` inside it. Register each
external repository or folder through a stable binding in `PROJECT.md`, with
machine-specific paths kept in ignored `.context-hub/local.yaml`.

Project `NOW.md`, `DECISIONS.md`, and `LEARNINGS.md` remain curated authority;
project `SUMMARY.md` and `OVERVIEW.md` are compact routing views.
