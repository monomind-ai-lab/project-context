# Plan

The current milestone, authored here by the builders. Use stable IDs such as
`M-001`. The lifecycle is `proposed` → `active` → `done` | `dropped`.

Where a Project Hub owner has pushed `blueprint/EPIC.md` into this repository,
every item below names the epic item it advances on a `- Serves:` line, and the
doctor errors on an item that names none. The epic says what the project is
for; this file says what this milestone does about it. Without a `blueprint/`
this file stands alone and nothing is checked against it.

## M-001: Example milestone item

- Status: `proposed`
- Serves: E-001
- Outcome: State what is true when this item is done, in terms someone could
  check without reading the work.
- Next action: The smallest step that moves it.
- Evidence: Link to the task, primary artifact, review, or result. Pin a
  repository path to the state it cites: `path/to/file@<commit>`.
