# Q-001: Question title

- Registry: [`Q-001`](../QUESTIONS.md)

## What is unresolved

State the question so that an answer would be recognisable as one. A question
nobody can answer in a sentence is usually two questions.

## What depends on it

The work that is blocked, or the work proceeding on an assumption. Name the
files if it touches files — an anchored question is one the assembler can put
back in front of whoever picks the work up.

## Assumption

- Assumption: What the work is proceeding on for now.
- Confirmed: Who checked it, and against what. Delete this line until someone
  has; `context_review.py` reports an assumption that has neither a
  confirmation nor an answer.

## Answer

Fill this in when it closes, set `status: answered`, and say who answered it.
An answered question is evidence for the decision it unblocked — link the two.
