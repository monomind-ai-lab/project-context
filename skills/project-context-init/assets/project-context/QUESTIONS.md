# Question Registry

Open questions and the assumptions work is proceeding on. Use stable IDs such
as `Q-001`. The lifecycle is `open` → `answered` → `superseded`.

File a question the moment a requirement is ambiguous rather than picking an
interpretation quietly — an assumption nobody recorded is indistinguishable
from a decision nobody made. Where a Project Hub owner is reading this
repository, an open question reaches them at their next `/hub-pull`; nothing
here needs their permission to write.

## Q-000: Example question

- Status: `open`
- Date: YYYY-MM-DD
- Question: State exactly what is unresolved, and what depends on the answer.
- Assumption: What the work is proceeding on until the question is answered.
  Remove this line, or add a `Confirmed:` line beside it, once someone checks.
- Answer: Fill this in when the question closes, and set `Status: answered`.
- Evidence: Link to whatever raised the question. Pin a repository path to the
  state it cites: `path/to/file@<commit>`.
