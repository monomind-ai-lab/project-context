# Capsule title

What happened, and why a future contributor would want to know. Two hundred
words at most.

- Evidence: Pin a repository path to the state it cites:
  `path/to/file@<commit>`, or use the reference grammar —
  `session:<harness>:<id>`, `commit:<binding>:<sha>`, `pr:<binding>#<number>`.

## Promotion

Which registry this belongs in, if any: a `decision` if it constrains future
work, a `learning` if evidence changed what is believed and it will recur, a
`question` if it is unresolved. Set `status: accepted` when it has been
promoted and link the record it became; set `status: rejected` when it has been
read and does not belong anywhere.
