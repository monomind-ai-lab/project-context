# Inbox

Capsules land here: short, dated notes captured during work that have not yet
earned a place in a registry. `project-context capture` writes them; a person
or an agent promotes them into a decision, a learning, or a question, or drops
them.

The point of the staging step is that capture must be cheap enough to happen
during the work and promotion must be deliberate enough that the registries
stay readable. A capsule that is never promoted is not a failure — it is a note
that turned out not to matter — but one sitting here for weeks is something
`context_review.py` will keep raising until someone decides.

A capsule is at most 200 words. Anything longer is the record it should become.
